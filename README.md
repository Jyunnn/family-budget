# 家庭記帳日曆

一個家庭記帳應用程式，協助夫妻倆管理月度預算和追蹤日常支出。

## 功能特色

✨ **主要功能：**
- 🗓️ 日曆式支出記錄 - 每天的花費一目了然
- 💰 預算管理 - 設定家庭月度預算
- ⚠️ 預算告警 - 在達到 50%、30%、20%、10% 時提醒
- 👥 角色分類 - 區分丈夫和老婆的支出
- 📊 支出分類 - 食物費、交通費、娛樂、帳單、其他
- 💾 本地存儲 - 數據自動保存在瀏覽器本地

## 技術棧

- **框架：** Vue 3 + Vite
- **狀態管理：** Pinia
- **日期處理：** date-fns
- **部署：** IIS / 靜態服務器

## 快速開始

### 開發環境

```bash
# 安裝依賴
npm install

# 啟動開發伺服器（http://localhost:5174）
npm run dev

# 構建生產版本
npm run build

# 預覽構建結果
npm run preview
```

### 使用流程

1. **打開應用** - 訪問首頁，可看到當月日曆
2. **設定預算** - 點擊 "⚙️ 設定預算" 按鈕設置本月預算
3. **新增支出** - 點擊日期單元格，填寫以下信息：
   - **金額** - 支出的金額
   - **類別** - 選擇支出類型
   - **角色** - 選擇是丈夫還是老婆
4. **查看記錄** - 支出會實時顯示在日期下方
5. **預算提醒** - 超過預算時會自動提醒

## 部署到 IIS

### 前置要求
- IIS 已安裝並配置
- 靜態內容服務已啟用

### 部署步驟

1. **構建應用**
   ```bash
   npm run build
   ```

2. **上傳到 IIS**
   - 將 `dist` 文件夾內容上傳到 IIS 站點目錄
   - 例如：`C:\inetpub\wwwroot\family-budget\`

3. **配置 IIS 站點**
   - 在 IIS 管理器中創建新網站或應用程式
   - 設置物理路徑指向上傳的目錄
   - 確保應用程式池使用 .NET CLR 版本「無受管程式碼」

4. **驗證部署**
   - 訪問 `http://yourdomain.com/family-budget`
   - 測試日期點擊、新增支出、設定預算等功能

### 常見問題

**Q: 刷新頁面後 404 錯誤？**
- A: 確保 `web.config` 已上傳到 `dist` 目錄並正確配置了 URL 重寫規則

**Q: 樣式或 JavaScript 無法加載？**
- A: 檢查 IIS 的 MIME 類型配置，`.js` 文件應映射為 `text/javascript`

**Q: 數據沒有保存？**
- A: 確保瀏覽器允許本地存儲。檢查開發工具控制台是否有錯誤

## 預算告警規則

應用會根據剩餘預算百分比顯示不同的警告：

| 剩餘百分比 | 提示類型 | 消息 |
|----------|--------|------|
| > 50% | 無 | 正常 |
| 50% | 提醒 | 本月預算已使用一半 |
| 30% | 提醒 | 本月預算剩餘 30% |
| 20% | 注意 | 本月預算剩餘不到 20% |
| 10% | 警告 | 本月預算僅剩不到 10% |
| ≤ 0% | 緊急 | 本月預算已用罄 |

## 數據存儲

所有數據使用瀏覽器 LocalStorage 存儲，包括：
- **monthlyBudget** - 當月預算金額
- **records** - 所有支出記錄（包含日期、金額、類別、角色）

## 開發建議

- 使用現代瀏覽器（Chrome、Firefox、Safari、Edge）
- 定期備份 LocalStorage 中的數據
- 如需多設備同步，可考慮添加後端 API
